# Java & POO Practice Repository

This repository contains my personal Java practice exercises for the Object-Oriented Programming (POO) course I am following on OpenClassroom.

This project is part of my training work and is used to experiment with core Java concepts such as classes, objects, encapsulation, inheritance, composition, exceptions, collections, and project organization.

## 🧩 Project context

This is a learning project related to my OpenClassroom TP (practical work) for the Java and OOP course. I am putting my practice and experiments here so I can track my progress and keep my code organized.

## 📌 What this project covers

The current exercises focus on a small Java application named "Epicrafter's Journey". The project demonstrates:

- Object-oriented design with several classes and interfaces
- Use of collections and maps
- Factory pattern for creating building blocks
- Custom exceptions handling
- Java logging with Log4j2
- Basic user interaction through the console

## 📁 Repository structure

- `src/ej/` : main Java source code
- `src/ej/blocs/` : classes representing building blocks and related logic
- `src/ej/exceptions/` : custom exception classes
- `src/ej/kits/` : startup kit logic
- `kit.txt` : example content used by the project
- `log4j2.properties` : logging configuration
